# Atlyn Profile Lens privacy statement

Effective date: 2026-09-17

This statement applies specifically to **Atlyn Profile Lens**, GUID `atlynProfileLens`, distributed
as a Microsoft Power BI custom visual.

## Report data

Power BI supplies the visual with the fields, values, formatting settings, selections, and host
context chosen by the report author. Atlyn Profile Lens processes that information inside the Power
BI visual host only to render the profile chart, offline context surface, tooltips, accessibility
content, and report interactions requested by the user.

Atlyn Profile Lens does not intentionally transmit report data, rendered report content, selections,
or usage telemetry to Atlyn or any third party. It does not store a copy of report data outside the
Power BI host. The package requests no Power BI privileges, contains no WebAccess privilege, makes no
external network requests, and uses only bundled offline cartography.

Microsoft Power BI and the report owner's organization control the report, workspace, access,
retention, diagnostics, and governance under their own policies.

## Accounts, payments, and the Atlyn website

Atlyn Profile Lens does not require a visual-specific account, license key, sign-in, subscription
check, or in-app purchase. The separate Atlyn website may process account, payment, support, and
website usage information as described in the
[Atlyn corporate privacy policy](https://www.atlynco.com/legal/privacy). Those website practices are
not part of the visual package's processing.

## Contact

For questions about this statement or a privacy request, contact
[support@atlynco.com](mailto:support@atlynco.com). Do not send report data or personal information
unless support requests it through an appropriate channel.
